Acerca del proyecto

Este simulador permite evaluar una supuesta evidencia OVNI y clasificarla como débil, moderada o fuerte según criterios definidos en el examen de Programación Web I. Además, guarda un historial de registros y ofrece una galería multimedia para ambientar la experiencia.

Proyecto recuperatorio - Programación Web I | Autor: Juan Fernando Vaqueros Arias
